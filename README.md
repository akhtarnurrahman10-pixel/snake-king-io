## 🎮 Features

### Game Modes (7)
- 💀 **Hardcore** — 1 life, high risk
- ❤️ **Casual** — 4 lives, relaxed
- 🔥 **Arena** — Shrinking map (Battle Royale)
- 🌊 **Survival** — AI gets smarter every 30s
- ⚔️ **PvP Duel** — 1v1 Titan Boss, 3 rounds
- 🎮 **Duo Local** — 2 players, 1 keyboard
- 👑 **Level Mode** — 40-level campaign

### Online Features
- 🗺️ **Map Marketplace** — Upload, download, vote
- 🏛️ **Hall of Fame** — Legendary maps forever
- 💬 **Community Chat** — Realtime (Supabase)
- 🔄 **Bi-weekly Rotation** — Fresh maps every 2 weeks

### Progression
- 🏆 **60 Achievements** (4 tiers)
- 🎯 **Daily Challenges** (50 pool, 5/day)
- 🎡 **Spin Wheel** — Gacha system with tickets
- 🎨 **71+ Animated Skins**
- 🔥 **Login Streak** — Daily rewards

### Editor & Tools
- 🛠️ **Custom Map Editor** (20 disasters, 20 decorations, 20 boosters)
- 📤 **Export/Import** — Share maps via JSON
- 📊 **Lifetime Stats** (9 metrics + K/D ratio)
- 🔥 **Death Heatmap** — See where players die most
- 🎬 **Replay System** — Last 10 seconds cinematic
- 👁️ **Spectator Mode** — Watch AI after death
- ⚙️ **Hardware Optimization** — 5 presets, auto-detect

### Technical
- ⚡ **281 KB** — 1 HTML file
- 🗄️ **2 Supabase Databases** (PostgreSQL + Realtime)
- 🎨 **Premium UI** — Design system, responsive, accessibility
- 🔒 **Auth System** — Email login/register
- 🚀 **Zero Framework** — Pure vanilla JavaScript
- 🤖 **Zero AI** — 100% human-made
